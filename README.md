# Greenden - Plant Store Website

**Greenden** is a modern, responsive plant store website built using **HTML5** and **Tailwind CSS**. This frontend project focuses on creating a clean, user-friendly shopping experience with a fully responsive design that works seamlessly across desktops, tablets, and mobile devices.

## Features

* Responsive navigation bar
* Modern homepage with hero section
* Product listing page
* Search bar for finding products
* Contact Us page
* Responsive product cards
* Clean and modern UI/UX
* Footer with essential links
* Mobile-friendly layout using Tailwind CSS utility classes

## Technologies Used

* HTML5
* Tailwind CSS
* Responsive Web Design
* Google Fonts
* Font Awesome Icons

## Pages

* Home
* Products
* Contact

## Components

* Navbar
* Search Bar
* Product Cards
* Contact Form
* Footer

## Purpose

This project was developed to strengthen my frontend development skills using Tailwind CSS and responsive web design principles. It demonstrates my ability to build modern, mobile-friendly interfaces with reusable utility classes, clean layouts, and an intuitive user experience. In future updates, I plan to add JavaScript functionality, product filtering, shopping cart features, and backend integration to create a complete e-commerce application.
